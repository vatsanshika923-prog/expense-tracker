# Expense Tracker

A command-line Expense Tracker built with Python.

## Features

- Add expenses
- View expenses
- Search by category
- Delete expenses
- Monthly summary
- Persistent JSON storage

## Technologies

- Python
- OOP
- JSON
- File Handling

## Run

```bash
python main.py
```
